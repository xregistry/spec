# OpenUSD Artifact Registry Service - Version 1.0-rc4

<!-- words: OpenUSD -->

This unreleased working draft describes an xRegistry for OpenUSD artifacts,
such as scene layers, packages, and textures. See the
[specification](spec.md) for registry behavior and the [model](model.json)
for the Group and Resource definitions.

The [generated schemas](../../tools/README.md) describe selected Registry
metadata in JSON Schema, JSON Structure, Avro and OpenAPI. Reproduction and
syntax checks do not establish complete model coverage.
